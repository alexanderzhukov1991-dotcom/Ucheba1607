# 📚 Учёба — тесты для школьника

Простой сайт с тестами по школьным предметам (4 класс). Работает без сервера и сборки —
бесплатно размещается на GitHub Pages. Результаты и звёзды сохраняются в браузере ребёнка.

## Как опубликовать сайт (GitHub Pages)

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
3. Выберите ветку (`main`) и папку **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Как добавить тест

Тесты лежат в папке `data/` — по одному файлу на предмет:

| Файл | Предмет |
|---|---|
| `data/math.js` | Математика |
| `data/russian.js` | Русский язык |
| `data/world.js` | Окружающий мир |
| `data/reading.js` | Литературное чтение |
| `data/english.js` | Английский язык |

Новый тест — это блок `TESTS.push({...})` в конце нужного файла:

```js
TESTS.push({
  id: "math-fractions-1",          // уникальный, латиницей
  subject: "math",
  topic: "Доли и дроби",           // раздел учебника
  title: "Нахождение доли числа",
  source: "Учебник, ч. 2, стр. 40", // необязательно
  questions: [
    // один вариант (answer — номер, счёт с нуля)
    { q: "Половина от 18 — это…", options: ["6", "9", "12"], answer: 1 },
    // несколько вариантов
    { q: "Какие дроби меньше 1?", options: ["1/2", "5/5", "3/4"], answer: [0, 2] },
    // ввод с клавиатуры (можно несколько допустимых ответов)
    { q: "Найди 1/4 от 20", answer: "5", explain: "20 : 4 = 5" }
  ]
});
```

Отредактировать файл можно прямо на сайте GitHub (иконка ✏️ у файла) — сайт обновится сам.

**Новый предмет:** добавьте строку в `data/subjects.js`, создайте файл `data/<предмет>.js`
и подключите его в `index.html` строкой `<script src="data/<предмет>.js"></script>`.

## Локальный просмотр

Достаточно открыть `index.html` в браузере.
